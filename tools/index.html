Tools for the games we play

Better tools.
Built for each game.

We are building practical companion tools for games with deep characters, builds, inventories and progression. Each one will be designed around the game itself, using its own systems and language, instead of forcing every game into the same mould.

Why we are building them

Bring the useful information
into one place.

Games often spread the information players need across character screens, inventories, loadouts, activity records and external services. We want to bring those pieces together, show how they connect and help players make sense of them without taking away what makes each game different.

01

All in one place

Your character, gear, progress and recent activity should work together instead of sitting in separate screens.

02

Made for each game

A Destiny tool should feel like it belongs to Destiny. Every future tool will follow the systems and language of its own game.

03

Clear and honest

If advice comes from live data, we will show that. If something is missing or still being tested, we will say so.

04

Ready to grow

The shared parts can be reused, so we can spend more time building the features that matter for the next game.

Destiny 2 Alpha · Invitation Only

Destiny 2 Guardian Platform

The first platform we are building is for Destiny 2. It starts with the Guardian and connects equipped gear, subclasses, saved loadouts, build analysis, recent activities and inventory into one tool instead of treating them as separate features.

Some sections are further along than others. The Alpha will remain invitation only while live data, recommendations and each page are checked properly.

More than one game

A shared base.
A tool made for its game.

When we build for another game, we can reuse the parts that should stay consistent, such as navigation, access, loading and mobile behaviour. The features that help the player will still be designed specifically for that game.

If a game offers official live data, we can connect it. If it does not, we will work with what players can provide and be clear about the limits.

Future route pattern astrixparadox.com/tools/{game}/
We will only announce the next game when we know exactly what its tool needs to do.
